# AffilateMarketing Application

This is a one kind of learnign application for those person who want to learn affilate marketing. It is a just Ui design with full responsive on both platfrom (Andriod and iOS)..

## Use some features (packages) from pub.dev

1. Provider State Management.
2. Video player
3. Image picker
4. Text copy when click the copy icon.
5. flutter_screenutil (Responsive for all device)
